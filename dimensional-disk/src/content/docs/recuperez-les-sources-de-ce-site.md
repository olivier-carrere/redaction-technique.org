1. Clonez le dépôt des sources de ce site :

    ```console
    $ git clone https://github.com/olivier-carrere/redaction-technique.org.git
    ```

2. Placez-vous dans le répertoire des sources de ce site :

    ```console
    $ cd redaction-technique.org
    ```
