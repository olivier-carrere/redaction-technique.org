## Documentation assistée par l'IA

Utiliser les LLM là où ils suppriment le travail mécanique, avec un humain dans la boucle et chaque modification relue sous Git : traduction, réponses fondées sur un corpus documentaire, et documentation exploitable par les programmes et les agents IA.

- [Interroger la documentation](/fr/ask/) : un assistant qui répond uniquement à partir des pages de ce portfolio, et cite les pages utilisées.
- [L'API documentaire](/fr/about-the-api/) : llms.txt, miroirs Markdown et index JSON générés à la compilation pour les scripts et les agents IA.
- [Translating legacy French docs to English with DeepL and GPT-4o](https://redaction-technique.org/ai-translation-legacy-technical-docs) (en anglais) : le workflow utilisé pour traduire ce portfolio, avec les diffs Git comme filet de sécurité.
- [Reliability vs. latency: running Claude through the CLI](https://redaction-technique.org/reliability-vs-latency-claude-cli) (en anglais) : boucler la boucle de rétroaction pour que le modèle corrige ses propres erreurs de compilation.
- [Persona prompting: check this before printing](https://redaction-technique.org/persona-prompting-typographer) (en anglais) : une revue technique structurée obtenue par un prompt ciblé.
