---
title: "Base de données SQL"
description: "Dans un CMS (Drupal, Joomla, WordPress), le contenu documentaire est stocké en base SQL. Implications pour la sauvegarde, la migration et la réutilisation du contenu."
---
Dans le cas d'un <abbr title="Content Management System">CMS</abbr> de type Drupal, Joomla ou WordPress, le référentiel est une base de données SQL. Il conserve un historique, mais uniquement article par article et ne permet pas la recherche et le remplacement de texte à travers tout le contenu. Cela peut justifier le choix de gérer le contenu sous-jacent du <abbr title="Content Management System">CMS</abbr> sous forme de fichiers texte.
