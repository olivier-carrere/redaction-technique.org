title: "Target format
description: "The target format of a technical writing medium is the format in which the message's audience will access it."
---

The target format of a **technical writing** medium is that in which the message's audience will access it. It is different from the format in which the **technical writer** creates the content. The *single-sourcing* process enables several deliverables in different formats to be generated from the same source format.

From validated source files, deliverables are generated using one of the following methods:

| Publication type | Example |
|--------------------------|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| For example, white paper from **DITA XML** structured format to PDF target format via <abbr title="DITA Open Toolkit">DITA-OT</abbr>.
| Semi-automatic | For example, content in **DITA XML** format exported to HTML then pasted into a CMS. | Manual
| For example, marketing brochure in word-processing format or **DITA XML** formatted in Indesign, exported as PDF, then printed. Depending on the frequency of publication of the final document, XML import filters can also be set up.

The more automated the process, the lower the risk of error, and the easier it is to publish and update. Automation also facilitates *single-sourcing*, which consists of generating several deliverables in different target formats from the same source format. A project in **DITA XML** format can thus be delivered as a PDF file, a Windows compiled help, a JavaHelp, an HTML site, and so on. In this respect, XML offers almost unlimited possibilities.
