In the case of a content management system (CMS) such as Drupal, Joomla, or WordPress, the repository is an SQL database. It maintains a history on a per-article basis, but does not support text search and replacement across all content. This may justify choosing to manage the underlying content of the CMS in the form of text files. For an example of querying an SQL database to populate documentation automatically, see [automatically insert SQL data into a reStructuredText file](../veille/inserer-automatiquement-des-donnees-sql-dans-un-fichier-restructuredtext/).
